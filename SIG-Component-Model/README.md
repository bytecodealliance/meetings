# SIG Component Model Meetings

A meeting for the Bytecode Alliance [Special Interest Group (SIG)](https://github.com/bytecodealliance/governance/blob/main/SIGs/SIG-component-model/) on the WebAssembly Component Model.

## Time and Location

**When**: every Thursday at 8am PST  
**Where**: On Zoom [link](https://zoom.us/j/91636826370?pwd=pzAH5fgnlyt00tS5H9Az2Tcxgzohx7.1)

Meeting information is also shared via the Bytecode Alliance public events calendar, which you can 
view [here](https://calendar.google.com/calendar/embed?src=events%40bytecodealliance.org&ctz=America%2FLos_Angeles),
and can access directly using [this link](https://calendar.google.com/calendar/ical/events%40bytecodealliance.org/public/basic.ics).

You're welcome to attend by using the Zoom video meeting link above.

## Agendas and Notes

Both agendas for upcoming and notes for past meetings will be posted in a public Google Document 
available [here](https://docs.google.com/document/d/1qJdr6UUdI6GNv05XdFKFTYEWp6w-IWgBBAeNldFrZ5M/edit?usp=sharing).

## Adding Agenda Items

To add something to the agenda for an upcoming meeting you're welcome to add it directly to the agenda
document linked to above, or post a message on [Zulip](https://bytecodealliance.zulipchat.com/#narrow/channel/637097-SIG-Component-Model) proposing a meeting topic.

## Live chat and Q&A

Can't make it to the meeting or have a topic to share with the community? Chat and Q&A is 
in the Bytecode Alliance Zulip [SIG Component Model channel](https://bytecodealliance.zulipchat.com/#narrow/channel/637097-SIG-Component-Model).
